# THYROID-PREDICTIONS

# 🦋 Thyroid Disease Risk Prediction using Machine Learning

This project focuses on **analyzing thyroid patient data and predicting disease risk levels** using multiple **classification and ensemble learning models**.

---

## 📌 Project Features

* End-to-End **Exploratory Data Analysis (EDA)**
* Duplicate Removal & Data Type Fixing
* **Categorical Encoding using One-Hot Encoding**
* Feature Scaling with **StandardScaler**
* Comparison of **9+ Classification Models**
* Final Accuracy Visualization & Model Ranking

---

## 📊 Dataset Summary

* **Total Records:** 364
* **Total Features:** 17
* **Target Variable:** Risk Level
* **Key Columns:** Age, Gender, Thyroid Function, Pathology, Stage, Response

---

## 🤖 Models Applied

* Logistic Regression
* Decision Tree
* Random Forest
* KNN ✅ *(Best Performer)*
* Support Vector Classifier (SVC)
* Voting Classifier
* Stacking Classifier
* Gradient Boosting
* AdaBoost

🏆 **Best Model:**
**KNN → Accuracy = 87.6%**

---

## 📈 Visualizations Covered

* Age Distribution Histogram
* Thyroid Function & Gender Analysis
* Stage vs Age Violin & Line Plots
* Correlation Heatmap
* Model Accuracy Comparison Bar Chart
